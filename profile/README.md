## Products / Ürünler

### [Verinoda](https://github.com/Verinoda-Labs/verinoda)
Evidence-first code intelligence for AI coding agents. Answers about a codebase come as claims with
`file:line` evidence and an explicit status (verified, inference, unknown), so agents read less, guess less
and stay honest as the code changes. CLI + MCP server: `pip install verinoda` or `npx verinoda`.

AI kodlama ajanları için kanıt öncelikli kod zekâsı. Cevaplar `file:line` kanıtı ve açık bir durumla
(doğrulandı, çıkarım, bilinmiyor) gelir; ajan daha az okur, daha az tahmin eder.

### [Verinoda Symbiosis](https://github.com/Verinoda-Labs/verinoda-symbiosis)
Verinoda + Claude Code, together. Includes `verinoda-live`, a Claude Code mod that keeps the code index
fresh, nudges the agent to use it, reviews commits, and shows it all in a pane.

Verinoda ve Claude Code birlikte: kod indeksini taze tutan, ajanı indeksi kullanmaya yönlendiren ve
commit'leri inceleyen bir Claude Code modu.
